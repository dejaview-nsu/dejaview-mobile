# dejaview-mobile

План Android-разработки для четырёх разработчиков: две недели на первую тестовую поставку и отдельный этап для остальных требований.

Подготовительный пакет обновлён по исходникам backend и данным Figma. Android-приложение ещё предстоит создать по задачам D1; проверки этого репозитория пока относятся к документации и инструментам.
