# Конфиденциальность материалов DejaView

В публичной части репозитория хранятся обезличенные требования, контракты, инструкции и код. Исходные PDF/FIG, сырые экспорты макетов, данные профилей, скриншоты с заполненными формами, локальные адреса файлов, персональные email и ссылки на закрытые дизайн-файлы остаются в игнорируемом `.local/`.

В примерах использовать `user@example.invalid`, `sample_user`, «Пользователь», Dev 1–4. Имена участников, пути домашних каталогов и реальные логины не нужны для описания архитектуры. Поля API `username`, `email`, `user_id` сохраняются: конфиденциальны значения, а не имена полей. Публичные URL исходного кода допустимы; временные подписанные URL выгрузки Figma и ключ файла не публикуются.

## Проверка перед передачей и публикацией

```text
python scripts/privacy_check.py
python scripts/privacy_check.py --staged
python -m unittest discover -s scripts/tests
```

Первая команда проверяет отслеживаемые и неигнорируемые новые файлы. Вторая проверяет именно байты Git index: очищенный рабочий файл не скрывает старую staged-копию. Результат содержит только путь внутри repo, строку и тип нарушения, не найденное значение. Игнорируемые входы не сканируются для публикации, но принудительно добавленный в Git файл из `.local/` будет проверен.

Для локальной проверки имён и специфических идентификаторов создайте `.local/private-terms.json` — JSON-массив строк — и выполните `python scripts/privacy_check.py --private-terms .local/private-terms.json`. Сам список не публикуется. Автоматика не умеет достоверно отличать любое имя человека от обычного текста и не выполняет OCR. Перед публичной передачей нужен ручной просмотр текстов/метаданных и изображений. В текущем режиме бинарные документы и медиа в публичном дереве блокируются до отдельного согласованного процесса обезличивания.

Исключение для Gradle Wrapper действует только для `android/gradle/wrapper/gradle-wrapper.jar` с опубликованной контрольной суммой закреплённой версии. При обновлении Wrapper сверяйте новый SHA-256 с [Gradle release checksums](https://gradle.org/release-checksums/) и обновляйте значение в проверке.

## Обезличивание и история

Сохранённые OpenAPI-копии очищены от `example`/`examples`; описательные email заменены синтетическими. Это обозначенные производные контракта, а не побайтовые архивные оригиналы. Поля, типы, required, enum, paths и responses сохранены. Исходники, если нужны для сверки, остаются приватными.

Удаление из рабочей копии не удаляет сведения из уже опубликованной истории Git. На момент первичной подготовки в checkout был только исходный README. Последующие коммиты сохраняют историю; проверять нужно актуальный diff и index, не предполагать отсутствие публикаций. Проверка не меняет git author/email, права репозитория или историю удалённого сервера. Если какие-либо материалы уже публиковались из другого checkout, их историю и кэши нужно проверить отдельно. Переписывание истории и force push выполняются только как отдельная согласованная задача.

## Материалы Figma

В текущем макете присутствуют заполненные примеры пользовательских данных. Не считать их автоматически вымышленными. Поэтому полные JSON, PNG и SVG выгружаются в `.local/design/`; публичный каталог содержит только технические ID, названия экранов, размеры и проверенные дизайн-токены. Изображение не становится обезличенным от удаления metadata: адрес или имя может быть нарисовано внутри него.

При передаче приватного пакета команде использовать согласованное закрытое хранилище. Для работы агенту достаточно его выбранного экрана и общих токенов; загружать весь файл в произвольные онлайн-конвертеры не требуется.
