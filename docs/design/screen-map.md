# Соответствие экранов PDF и Figma

PDF фиксирует требования и сценарии; Figma — визуальные состояния. Номер без названия и nodeId недостаточен: есть повторения номеров в секции вне MVP. Полный перечень — [88 фреймов](screens.md), машинный вариант — [screens.json](screens.json).

| Упоминание в прежнем плане / PDF | Что находится в Figma | Как использовать |
| --- | --- | --- |
| 2.3а как crop | 2.3а — нет доступа к камере | Не реализовывать crop по этому frame; камера и crop вне двухнедельной поставки |
| 4.2 как отдельная оценка | 4.2 — карточка после прокрутки | Часть карточки Dev 1 |
| 4.3 как редактор отзыва | 4.3 — оценка | UI оценки Dev 2, вызов из карточки Dev 1 |
| 4.3/4.4 как формы отзывов | 4.4 — новый отзыв | Этап 2, Dev 2 |
| 5.9 как история | 5.4 — история поиска | MVP Dev 3 |
| 5.9 в профиле | 5.9 — имя пользователя | Редактирование профиля этапа 2 |

Это исправления плана, а не переписывание первичного извлечения PDF. При дальнейшем расхождении записывать UC, ожидаемое поведение, фактические name/nodeId и решение владельца; не менять продуктовый scope по одному заголовку frame.

Из 88 верхнеуровневых frames 66 имеют номер экрана: 52 в основной части и 14 в секции «Вне MVP». Ещё 4 относятся к дизайн-системе, 7 к адаптивности/iOS и 11 к анимации заставки. Это количество frames, не количество уникальных пользовательских функций. Страница внутренних переменных также разобрана, но экранов не содержит.
