2. **Стенд.** Получить адрес, deploy commit и синтетические аккаунты; проверить cookies/CAPTCHA и реальные поиски. Это не мешает начинать scaffold, UI и локальные контрактные проверки.
3. **Точные изображения.** Figma вернула ссылки на семь PNG, но загрузка дала HTTP 202 без данных; затем достигнут лимит запросов. Валидных PNG сейчас нет. Запустить подготовленный development plugin в Figma Desktop, проверить manifest/errors и все нужные изображения. Сам плагин ещё не запускался в редакторе.
4. **Ревью и публикация.** Все изменения пока локальные, без commit/push. Перед публикацией просмотреть diff, выполнить privacy-check, после staging проверить index. Проверка этого checkout не является аудитом истории сторонних репозиториев, уже разосланных файлов или удалённых кэшей.

Полные JSON/PNG/SVG макетов не должны оказаться в публичном PR. Для команды нужен согласованный приватный канал хранения, поскольку в дизайне есть заполненные персональные примеры.
