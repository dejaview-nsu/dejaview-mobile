# Покрытие требований DejaView по этапам

Сверка источников: [реализация backend](backend-evidence.md), [номера экранов Figma и PDF](../design/screen-map.md). Этапы обозначают объём Android, а не отсутствие серверного кода.

Номера UC, FR и экранов взяты из PDF, страницы 14–34. **MVP спринта** — сокращённая первая поставка из [основного плана](README.md). **Этап 2** — завершение возможностей, названных MVP в PDF. **Этап 3** — функции, уже отмеченные в PDF как вне MVP. Эта матрица не меняет исходные требования и не означает, что их реализация завершена.
